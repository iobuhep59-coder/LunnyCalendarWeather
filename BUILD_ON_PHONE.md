# Как получить APK только с телефона

Этот проект подготовлен для облачной сборки через GitHub Actions. GitHub умеет запускать workflow вручную и сохранять собранный APK как artifact.

## Что делать

1. На телефоне открой GitHub и создай бесплатный аккаунт, если его нет.
2. Создай новый репозиторий, например `LunnyCalendarWeather`.
3. Загрузи в него содержимое этой папки так, чтобы `gradlew`, `settings.gradle.kts` и папка `app` находились в корне репозитория.
4. Открой вкладку **Actions**.
5. Выбери workflow **Сборка APK**.
6. Нажми **Run workflow**.
7. После окончания открой завершившийся запуск и скачай artifact **lunny-calendar-weather-apk**.
8. Внутри ZIP будет `app-debug.apk`. Нажми на APK на телефоне и установи его.

GitHub Actions выполняет сборку на сервере, поэтому Android Studio на телефоне не нужна.
