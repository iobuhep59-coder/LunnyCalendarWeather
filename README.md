# Лунный календарь и погода

Полноценное Android-приложение на Kotlin + Jetpack Compose + Material 3. Интерфейс полностью на русском языке.

## Возможности
- лунный календарь по месяцам и неделям;
- локальный расчёт фазы Луны, возраста и освещённости;
- ближайшие новолуние и полнолуние;
- прогноз Open-Meteo на ближайшие дни;
- температура, осадки, вероятность осадков, рассвет и закат;
- поиск городов и регионов через Open-Meteo Geocoding;
- сохранение последнего города и последнего прогноза через DataStore;
- работа лунного календаря и анекдотов без интернета;
- 40 встроенных приличных анекдотов;
- светлая/тёмная тема определяется системной темой Material 3.

## Требования
Android 7.0 (API 24) и выше. Целевая версия — API 35.

## Открытие
Откройте каталог проекта в Android Studio. Android Studio автоматически использует Gradle Wrapper, если он присутствует.

## Сборка
Из корня проекта:

```bash
./gradlew assembleDebug
```

APK после сборки: `app/build/outputs/apk/debug/app-debug.apk`.

Для release:

```bash
./gradlew assembleRelease
```

APK: `app/build/outputs/apk/release/app-release.apk`.

В демонстрационной сборке используется стандартная debug-подпись Android. Для публикации в Google Play создайте собственный release keystore и подключите его в `signingConfigs`.

## Установка
Скопируйте APK на телефон и откройте его. Если Android попросит разрешить установку из неизвестного источника, разрешите её для приложения, которым открывается APK.

## Интернет и API
Используются только HTTPS-запросы без API-ключа:
- Open-Meteo Forecast API: `https://api.open-meteo.com/`
- Open-Meteo Geocoding API: `https://geocoding-api.open-meteo.com/`

Фазы Луны вычисляются локально на основе синодического месяца и эталонной даты новолуния; внешний лунный API не требуется.

## Разрешения
- INTERNET — загрузка прогноза и поиск мест;
- ACCESS_NETWORK_STATE — определение сетевого состояния;
- ACCESS_COARSE_LOCATION / ACCESS_FINE_LOCATION — подготовлены как опциональные разрешения для геолокации.

Приложение не требует геолокации для работы: город можно выбрать вручную.

## Оффлайн
При ошибке сети используется последний сохранённый прогноз, а лунный календарь и анекдоты продолжают работать. Показывается сообщение «Нет подключения к интернету. Показаны сохранённые данные.»

## Тесты
```bash
./gradlew test
```
Проверяются диапазон освещённости и возраста Луны, эталонное новолуние, а также русские описания погодных кодов.
